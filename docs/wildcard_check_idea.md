# wildcardルール検証アイデアメモ

## レベル
| レベル | 名称 | レビュー方法 | ミスへの対策 |
|---|---|---|---|
| 0 | 手動レビュー | 自動レビューを行わず、ユーザーが確認する。 | ミスを検知する仕組みがないため、ユーザーが正しく判断できるよう、明確な案内を行う必要がある。 |
| 1 | 警告付き手動レビュー | 自動レビューを行い、問題を検知した場合は警告を表示する。最終的な判断はユーザーが行う。 | 警告によってミスを防げる可能性はあるが、完全には防げないため、明確な案内を行う必要がある。 |
| 2 | 自動レビュー | 自動レビューを行い、問題がなければ手続きを許可し、問題があれば拒否する。 | 自動レビューによって人為的な確認ミスを防止する。 |

## risk
HIGH
- reject: 審査対象にならない
- dq: 失格。調査のあと確定するものを含む
- red: 即レッドカード。即失格と同じ

LOW
- warn: 警告。単体では失格ではない 警告2回でイエロー。イエロー保持中の追加警告はレッド＝失格
- penalty: 順位を下げる。失格ではない 超過・不足した秒数ぶん最終順位が下がる
- admin: 動画内容ではなく、合格後の手続きや年齢で失格になる(事例無し。重要度低)

## ルール一覧
### NO-SHORT 通常動画として公開する
- level: 2
- risk: HIGH
- 実装: フロントの Shorts URL 即拒否 + バックエンド `NoShort`（`/shorts/{id}` へリクエストし最終 URL に `/shorts/` が残るか）+ 不合格時は審査中断

### GEN-VISIBILITY 動画を一般公開する
- level: 2
- risk: HIGH
- 実装: 提出ゲート `GateYoutube` + バックエンド `GenVisibility`（public / premiere のみ可）。非公開・限定公開は拒否。プレミアはファイル追加提出へ誘導

### TITLE-FORMAT 動画タイトル
- level: 2
- risk: ???
- 実装: フロントで oEmbed タイトル取得 → `titleMatches`。不一致なら提出前に中断
- 表記揺れは過去許してきた。SBXと調整すべき。あとから編集できる

### INTRO-REQUIRED 冒頭の自己紹介
- level: 1
- risk: LOW
- 実装: バックエンド `IntroRequired`（冒頭30秒 Whisper + Jev）。不合格時は警告表示、続行可
- 対象セリフ例:

My name is [ARTIST NAME], and this is my [CATEGORY] wildcard for the GBB2026 World League.

- 正直LOWだからあんまり考えなくていい
- 過去、名前は日本語で名乗って通った事例あり。そんなに厳しくとっていない

### INTRO-SAME-TAKE 自己紹介は本編と同じ場所で収録
- level: 1
- risk: HIGH
- 実装: バックエンド `IntroSameTake`（0:02 と 1:00 のコマを画像判定）+ 誓約。不合格時は警告表示、続行可。フロントにコマ比較 UI あり
- 失格事例あるので強調すべき
- 過去の事例から推察するに、SBXは見た目しか見ていない。時刻はどうでもいい

### SUB-RAW 生ファイルの提出
- level: 1
- risk: HIGH
- 実装: YouTube提出のとき、公開リンクを1回だけ開く（`SubRaw`）。401/404/410 とログイン着地だけ警告。403/5xx や中身・期限は見ない。不合格でも続行可。ファイル提出では求めない
- 存在はチェックできても、SBXが満足するかは別。追加提出を求められて、紛失してたら詰み。中身と期限は誓約でカバーする

### SYNC-LIVE 映像と音声は同時収録。リップシンク禁止
- level: 0
- risk: HIGH
- 実装: 誓約
- これをやるやつは悪意を持っているので無理

### AUDIO-PROCESS 許可される音声加工と即レッドカード
- level: 0
- risk: HIGH
- 実装: 誓約
- これを破った話はほとんど聞かない・判定困難

### ADMIN-AGE 年齢制限
- level: 0
- risk: HIGH
- 実装: 誓約（案内）

### ADMIN-CALL 優勝時のビデオ通話
- level: 0
- risk: HIGH
- 実装: 誓約（案内）

### TIME-PENALTY 演奏時間
- level: 0
- risk: LOW
- 実装: 誓約
- イントロ・アウトロの除外をした計算は困難。過去数十秒の違反をして結局勝った事例があるので、ここは取りこぼしを許す

### TEAM-VIS メンバーが常に映る
- level: 0
- risk: HIGH
- 実装: 誓約（tag / crew のみ）

### VIS-FACE 顔が常に判別できる
- level: 0
- risk: ???
- 実装: 誓約（solo / loopstation のみ）
- 正直誰も破らない

### SUB-ONCE 提出は1回だけ
- level: 0
- risk: HIGH
- 実装: 誓約
- Googleフォームで提出する前ならできるので、そこの線引きを説明すべき（これは前例あり）
