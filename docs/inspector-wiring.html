inspector に何が入るか

YoutubeInspector という型名から実体が湧くのではなく、 GateYoutube(inspector) の引数として渡したオブジェクトが self.inspector にそのまま保存される。

1. 起動時に実体を作り、引数で渡す

左の変数名 inspector は、右のオレンジ枠のオブジェクトを指しているだけ。 GateYoutube(inspector) と書くと、その指し先がコンストラクタの仮引数 inspector に渡る。

2. self.inspector は「同じ実体への別名」

型注釈の YoutubeInspector は「inspect メソッドを持つもの」という約束事。 実行時に入る中身は、渡したものそのもの。ここでは YtDlpYoutubeInspector() で作った実体が入る。 Protocol から自動生成されるわけではない。

3. app.state はあとから取り出すための棚

app.state.gate_youtube に置いた時点で、その中の self.inspector はすでに YtDlp 実体を指している。 コントローラが棚から取り出したあとに中身が差し替わるわけではない。

コンストラクタ・型まわり メモリ上の実体（1個） app.state（取り出し用の棚）

対応するコード

main.py

inspector = YtDlpYoutubeInspector()
app.state.gate_youtube = GateYoutube(inspector)

gate_youtube.py

def __init__(self, inspector: YoutubeInspector) -> None:
    self.inspector = inspector
